# 프롬프트

작업 단위로 나눈 실행 프롬프트를 모아둔다. 각 파일은 한 번에 전부
실행하는 지시가 아니라, 독립적으로 실행 가능한 단계의 묶음이다.

## 두 갈래

`server/prompts/`의 `02` ~ `06`은 백엔드 구축 단계다. 이미 실행되었고
기록으로 남아 있다.

이 디렉터리의 `PLAN_*`은 포트폴리오에 적힌 확장 계획 항목에 대응한다.

| 파일 | 확장 계획 | 상태 |
| --- | --- | --- |
| `PLAN_01_DESIGN_TOKENS.md` | 1번 · 디자인 토큰 | 미착수 |
| `PLAN_02_GENERATOR.md` | 2번 · 생성기 | 미착수 |

3번(프로덕션 인증)은 백엔드 작업으로 상당 부분 대체되었으므로, 남은
범위를 다시 정의한 뒤에 프롬프트를 쓴다.

## 쓰는 방법

단계 하나를 그대로 붙여넣어 실행하고, 그 단계의 완료 조건을 만족한 것을
확인한 뒤 다음 단계로 넘어간다. 완료 조건은 대부분 "실행해서 확인한다"
형태로 쓰여 있다. 확인하지 않고 넘어가면 다음 단계의 전제가 무너진다.

여러 단계를 한 번에 실행하지 않는다. 단계를 나눈 이유는 각 단계가
독립적으로 되돌릴 수 있게 하기 위해서다.
